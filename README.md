## 🚀 Featured Project

### 🧾 Invoicer — Medical & Business Invoice System

`React` `TypeScript` `Node.js` `Express` `SQLite` `Nodemailer`

A self-hosted invoicing platform built for pharmacies and small businesses, covering the full billing workflow from inventory to printed invoices.

| Feature | Details |
|---|---|
| 🖨️ **Print Templates** | 4 templates (Modern, Classic, Minimal, Medical) — compact enough to fit 20 line items on a single A4 page, including mobile print |
| 💊 **DL Compliance** | Drug License numbers stored in user profile and auto-stamped on every invoice |
| 📅 **Flexible Expiry** | Supports both full date and Month/Year-only selection modes |
| 🔁 **Duplicate Guard** | Detects duplicate products in the invoice editor and prompts to increase quantity instead |
| ✉️ **Email Delivery** | Sends invoices via Gmail App Password (Nodemailer), with a `mailto:` fallback |
| 🛡️ **Admin Panel** | View all users, invoice counts, last activity, and toggle admin status |
| ⚙️ **Per-User Settings** | Company profile, DL numbers, doctor name autofill, email configuration |
